# 📝 Vuetify Notes

Простое приложение для заметок, созданное с использованием **Vue 3** и библиотеки компонентов **Vuetify**.  
Проект выполнен в рамках учебного задания по теме «Библиотека Vuetify».

## 🚀 Функциональность

- Добавление новых заметок (ввод с клавиатуры или по кнопке)
- Отметка важных заметок (звёздочка)
- Удаление заметок
- Переключение между светлой и тёмной темой
- Две страницы: «Заметки» и «О приложении»
- Адаптивный интерфейс в стиле Material Design

## 🛠 Используемые технологии

- [Vue 3](https://v3.vuejs.org/) (Composition API)
- [Vuetify 3](https://next.vuetifyjs.com/) (Material Design компоненты)
- [Vue Router](https://router.vuejs.org/) (маршрутизация)
- [Vite](https://vitejs.dev/) (сборщик)
- [MDI Fonts](https://materialdesignicons.com/) (иконки)
